# 内容、SEO 与发布规范

## 当前网站

英文主站，42 条 2026/27 赛季主巡回赛与资格赛记录，12 个月页面，全年页面，5 个重点赛事详情，4 位球员介绍，2 篇日期简报，4 篇原创指南/历史文章，关于、联系、编辑政策、隐私、条款页面。共 37 个可索引内容页面。尚未覆盖女子、元老和 Q Tour。无实时比分，也不自动更新新闻。

## 数据与编辑

- `content/events.ts` 保存赛事起止日期、类型、地点、来源、差异说明。所有日期以赛场当地的日历日表达。资格赛独立于正赛。赛程跨月时两个页面都展示同一记录。
- `content/articles.ts` 保存原创文章、描述、分类、真实发布日期、段落与来源。`content/players.ts` 保存球员事实与观看提示。
- 当前核验日期是 2026-09-05；重新构建不代表重新核验。更新事实后，同时更新相关页面展示与结构化数据日期。后续迭代应把各记录独立核验日期纳入数据模型。
- 优先级：当前赛事官方页面 > 官方赛历 > 可信专业数据源。旧版官方赛历出现 Xi’an Grand Prix，而当前 WST 列出 Shenzhen Open；保留说明，不混用名称。
- 不复制第三方整篇文章、未经授权的照片或赛事商标；没有许可的球员图像不使用。不得编造比分、采访、作者资历、伤情、排名、现场见闻或读者反应。
- AI 辅助草稿必须经事实核查和出版者编辑审阅。网站公开说明了本版的 AI 辅助性质；没有伪造记者身份。
- 新文章必须回答明确的问题，提供来源及独立分析。不要用机械同义改写、堆关键词或大量低价值程序化页面换取数量。
- 重大错误在原文添加更正记录。公开邮箱当前为 jieliang17@gmail.com；在 `lib/site.ts` 统一替换。

## 技术 SEO

- 服务于静态 HTML 的页面正文在没有 JavaScript 时可读，不依赖爬虫执行客户端请求。
- 每页唯一 title、description、canonical；语义 h1、导航、正文内部链接。
- JSON-LD：WebSite、Article、ProfilePage、SportsEvent、BreadcrumbList。未捏造评分、票价、库存、作者履历或新闻图片。结构化数据不保证获得富媒体展示。
- 自动生成 `sitemap.xml`、`robots.txt`、RSS。站点地图只包含实际页面；不加入筛选 query、下载或空语言页面。
- `NEXT_PUBLIC_SITE_URL` 是完整公开站点根地址（项目子目录站点必须含子路径），`NEXT_PUBLIC_BASE_PATH` 是部署子路径。独立域名或用户级 github.io 站点使用空 basePath。
- 更换域名必须重建 canonical、站点地图、RSS、结构化数据和资源链接。不要在旧地址和新地址同时发布互相矛盾的 canonical。
- 当前字体为系统字体，不请求第三方字体。所有 UI 资源本地构建；没有第三方图片追踪请求。
- 对非现有 URL 返回 404，不能把所有未知路由重定向到首页制造 soft 404。
- 启用 Search Console，验证实际所有权，提交新域名 sitemap；检查真实收录和 Core Web Vitals，而不是承诺排名。

## AdSense 准备状态

已实现：明确导航、原创正文、公开联系渠道、关于与编辑政策、隐私/条款、无未经授权图片、无伪造事实、无诱导点击、无广告伪装导航。

尚未代表已通过审核。出版者必须在申请前完成：
1. 人工审核首发文章与赛程并持续提供有价值的内容。Google 没有公开统一的最低文章数、字数或流量门槛，不能保证通过率。
2. 确认联系信息、出版责任与实际数据处理方式；现有隐私文案为上线起点，需要按实际运营与司法辖区审阅。
3. 使用真实域名/网站及实际 AdSense 账户提交审核；不要使用虚构 publisher ID。
4. 根据账户提供的方式加入所有权验证。账户激活、审核通过与广告实际显示是不同步骤。
5. 按 AdSense 账户指示填写真正的 `ads.txt`。目前没有占位或虚假的授权广告商记录。
6. 在适用地区投放广告前，配置 Google 认证且整合 TCF 的 CMP，尤其针对 EEA、英国、瑞士。当前无广告或分析脚本，不用一个假的自制 cookie 弹窗宣称满足 CMP 要求。
7. 上广告前更新隐私、广告披露及相应数据处理；广告明确标记，不靠近容易误触的下载按钮或导航。
8. 通过真实用户测试与性能数据验证移动端、无障碍、可读性和广告布局。未进行浏览器截图或全量交互 QA，不宣称已经完成。
